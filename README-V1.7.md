# V1.7 — Mobil İlk / Profesyonel Görsel Patch

Bu patch V1.6 üzerine uygulanmalıdır.

## Değişiklikler
- Ana sayfa hero görseli gerçek servis fotoğrafı `camasir-makinesi-servis-07.jpeg` ile değiştirildi.
- Eski "Bu V4.2 sürümünde..." metni tüm public Türkçe HTML sayfalarından kaldırıldı.
- Mobilde daha önce gizlenen üst bilgi satırı yeniden görünür hale getirildi.
- Üst satıra tıklanabilir `EN • English Support` bağlantısı eklendi.
- Mobilde İngilizce bağlantısı sağ üstte kompakt bir buton olarak görünür.
- İngilizce sayfa `en/index.html` olarak doğru klasör yapısına alındı ve görsel yolları düzeltildi.
- Tuzla metinleri İngilizce sayfaya da işlendi.

## GitHub yükleme
1. ZIP'i çıkarın.
2. İçindeki `index.html` ve diğer HTML dosyalarını mevcut repository köküne yükleyin ve değişen dosyaların üzerine yazın.
3. `assets/style.css` dosyasını repository'deki `assets/style.css` üzerine yazın.
4. `en/index.html` yolunu klasör yapısını koruyarak yükleyin. Repository'de sadece `en-index.html` varsa bu dosya eski/yanlış konumlu kopyadır; `en/index.html` kullanılmalıdır.
5. `camasir-makinesi-servis-07.jpeg` dosyasını `assets/images/gercek-servis/` klasörüne yükleyin. Bu fotoğraf kullanıcı tarafından sağlanan gerçek servis fotoğrafıdır; içerik değiştirilmemiştir.
