# Dr. Beyaz Eşya – V4.8.2 Site Yönetim Paneli

`site-editor.html` dosyasını Chrome veya Edge ile açın.

1. **Siteyi Aç** → V4.8.2 site klasörünü seçin.
2. Panelden işletme bilgileri, ana sayfa, hizmet kartları, SEO ve fotoğrafları düzenleyin.
3. **Kaydet** butonuna basın.
4. Önce sitenin yerel kopyasını test edin, sonra GitHub Pages'e yükleyin.

## Fotoğraf ekleme
Fotoğraf Yöneticisi'nde görsel seçin ve `assets/images/gercek-servis/` klasörüne kopyalayın. Panel görseli düzenlemez; dosyayı olduğu gibi kopyalar.

## Gereksinim
Chrome veya Edge gibi File System Access API destekleyen güncel bir tarayıcı kullanın.

## Güvenlik
Panel sunucuya veri göndermez. Seçtiğiniz klasördeki dosyaları doğrudan tarayıcı üzerinden düzenler. İlk kullanımdan önce site klasörünün yedeğini alın.
