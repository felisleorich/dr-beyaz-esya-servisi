# Dr. Beyaz Eşya Servisi – V5.1 Site Yönetim Paneli

`site-editor.html` dosyasını Chrome veya Edge ile açın.

## Kullanım
1. **Siteyi Aç** ile bilgisayarınızdaki V5.1 site klasörünü seçin.
2. İşletme bilgileri, ana sayfa, hizmetler, SEO veya fotoğrafları düzenleyin.
3. **Kaydet** butonuna basın.
4. Değişiklikleri yerel kopyada test edin.
5. Sonrasında GitHub Pages'e yükleyin.

## Fotoğraflar
Gerçek servis fotoğrafları için önerilen klasör:

`assets/images/gercek-servis/`

Panel fotoğrafı yeniden düzenlemez; seçilen dosyayı olduğu gibi site klasörüne kopyalar.

## V5.1 notu
Sitenin güncel CSS yolu `assets/style.css?v=5.1` şeklindedir. Eski `assets/assets/` görsel yolu kullanılmamalıdır.

## Gereksinim
Chrome veya Edge gibi File System Access API destekleyen güncel bir tarayıcı kullanın.

## Güvenlik
Panel sunucuya veri göndermez. Seçtiğiniz klasördeki dosyaları doğrudan tarayıcı üzerinden düzenler. Değişikliklerden önce site klasörünün yedeğini alın.
